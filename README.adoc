== About The Project

A bespoke, minimalist architectural theme for Antora documentation, inspired by the "Stone and Graphite" design system.

IMPORTANT: Use the GitHub release `ui-bundle.zip` in your playbook—the habit to adopt.
The npm package `@amdphreak/architexture-theme-antora` is deprecated and unpublished.
link:https://antora-supplemental.github.io/architexture-theme/architexture-theme/guide/npm-deprecation.html[npm deprecation (lessons learned)]
Catalog: link:https://antora-supplemental.github.io/docs/[Antora Supplemental docs].

=== Design Philosophy

* **Neutral Palette**: Stone and Graphite high-contrast scheme.
* **Structural Integrity**: 1px borders, structural grids, and monospace technical metadata.
* **Minimalism**: Focus on content hierarchy and architectural honesty.

=== Hosting Strategy

This project uses a **Path-Based Routing** strategy for GitHub Pages to host both the **Docs** and **Demo** within a single instance:

* **Docs**: https://antora-supplemental.github.io/architexture-theme/architexture-theme/0.1/guide/index.html
* **Demo**: https://antora-supplemental.github.io/architexture-theme/

== Usage

Configure your CI/CD (GitHub Actions) to output the builds into these specific subdirectories on the gh-pages branch.
